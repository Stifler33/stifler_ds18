## 🌡️ DS18B20-Reader

Небольшая библиотека для удобной работы с цифровыми **1-Wire** температурными датчиками **DS18B20** на **Linux**-системах (например, Raspberry Pi) через файловую систему `/sys/bus/w1/devices`.

Библиотека позволяет **обнаруживать** подключенные датчики, **присваивать** им **имена** и **постоянно обновлять** их значения температуры в фоновом потоке, что обеспечивает быстрый доступ к актуальным данным.

-----

### ✨ Ключевые изменения и Особенности

  * **Работа через CLI:** Добавлена возможность **обновления конфигурации** и **именования новых датчиков** прямо из командной строки.
  * **Улучшенная инициализация:** Функция `init_config` теперь принимает аргумент `start=True` для управления запуском фонового потока.
  * **Надежность:** Добавлена обработка исключений `FileNotFoundError` и `KeyError` для более стабильной работы при чтении данных и запросе несуществующих датчиков.
  * **Именованная конфигурация:** Позволяет присваивать легко запоминающиеся имена каждому датчику (хранится в `config.json`).
  * **Фоновое обновление:** Температура обновляется в отдельном потоке (`threading`), минимизируя задержки при запросе данных (при запуске как модуль).

-----

### ⚙️ Требования

Для работы с датчиками DS18B20 на вашей системе **Linux** должны быть активированы необходимые модули ядра (`w1-gpio` и `w1-therm`).

-----

### 🚀 Использование

Вы можете использовать библиотеку как **модуль** в вашем Python-коде или запускать ее как **скрипт** через командную строку для **инициализации**.

#### 1\. Инициализация (Первый запуск / Добавление новых датчиков)

Для обнаружения новых датчиков и присвоения им имен запустите файл через командную строку с флагом `-u` или `--update`:

```bash
python your_file_name.py --update
```

> **Примечание:** Замените `your_file_name.py` на фактическое имя вашего файла.

Скрипт найдет новые датчики и попросит вас ввести для них имена. Фондовый поток **НЕ будет запущен** при использовании этого режима.

> **Пример:**
> `Введите имя для датчика 28-00000xxxxx: temp_boiler`

После завершения будет создан (или обновлен) файл **`config.json`** с присвоенными именами.

#### 2\. Запуск в качестве модуля и Чтение температуры

Если вы используете код в другом Python-скрипте, вам необходимо сначала вызвать `init_config()` для загрузки конфигурации и **запуска фонового потока**.

```python
import your_module_name # Замените на фактическое имя вашего файла/модуля

# Инициализируем конфигурацию и запускаем фоновое обновление температуры (start=True по умолчанию)
your_module_name.init_config()

# --- Далее в вашем коде ---

# Получение температуры (float по умолчанию)
temp_outside = your_module_name.get_temp("temp_outside")
if temp_outside is not None:
    print(f"Температура на улице: {temp_outside}°C")
else:
    print("Ошибка или датчик 'temp_outside' не найден/недоступен.")

# Получение температуры в виде строки
temp_inside_str = your_module_name.get_temp("temp_room", temp_type=str)
```

-----

### 📖 API (Основные функции)

| Функция | Описание |
| :--- | :--- |
| `init_config(start=True)` | Инициализирует конфигурацию, обнаруживает новые датчики, запрашивает имена и сохраняет `config.json`. Если `start=True` (по умолчанию), запускает **фоновый поток** для постоянного обновления данных. |
| `get_temp(name_sensor, temp_type=float)` | Возвращает температуру для указанного **имени датчика**. `temp_type` может быть `float` (по умолчанию) или `str`. Возвращает **`None`** в случае ошибки (датчик не найден или нет данных). |
| `list_devices()` | Возвращает **словарь** всех подключенных 1-Wire устройств, где ключ — это **адрес** датчика, а значение — его **путь** (`pathlib.Path`). |
| `run_parser()` | Обрабатывает аргументы командной строки. Используется для запуска через CLI с флагом `--update`. |

### 📄 Формат конфигурации (`config.json`)

```json
{
    "path_devices": "/sys/bus/w1/devices",
    "devices": {
        "имя_датчика": {
            "address": "28-00000xxxxx",
            "temp_raw": "25123",
            "temp_float": 25.123,
            "temp_str": "25.123"
        }
        // ... другие датчики
    }
}
```
