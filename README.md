## 🌡️ DS18B20-Reader

Небольшая библиотека для удобной работы с цифровыми **1-Wire** температурными датчиками **DS18B20** на **Linux**-системах (например, Raspberry Pi) через файловую систему `/sys/bus/w1/devices`.

Библиотека позволяет **обнаруживать** подключенные датчики, **присваивать** им **имена** и **постоянно обновлять** их значения температуры в фоновом потоке, что обеспечивает быстрый доступ к актуальным данным.

-----

### ✨ Особенности

  * **Автоматическое обнаружение:** Находит все подключенные датчики DS18B20.
  * **Именованная конфигурация:** Позволяет присваивать легко запоминающиеся имена каждому датчику (хранится в `config.json`).
  * **Фоновое обновление:** Температура обновляется в отдельном потоке (`threading`), минимизируя задержки при запросе данных.
  * **Простой доступ:** Предоставляет функции для получения температуры в **float** или **string**.

-----

### ⚙️ Требования

Для работы с датчиками DS18B20 на вашей системе **Linux** должны быть активированы необходимые модули ядра (`w1-gpio` и `w1-therm`).

-----

### 🚀 Установка и Запуск

Предполагается, что вы используете этот файл как модуль или скрипт в вашем проекте.

#### 1\. Инициализация (Первый запуск)

При первом запуске необходимо инициализировать конфигурацию, чтобы обнаружить датчики и дать им имена.

```python
import your_module_name # Замените на фактическое имя вашего файла/модуля

# Инициализируем конфигурацию.
# Это запустит поиск датчиков и попросит ввести имя для каждого нового датчика.
# Также запустится фоновый поток для обновления температуры.
your_module_name.init_config()
```

В процессе инициализации вам будет предложено **ввести имя** для каждого нового обнаруженного датчика.

> **Пример:**
> `Введите имя для датчика 28-00000xxxxx: temp_boiler`

После инициализации в каталоге скрипта будет создан файл **`config.json`**, в котором хранятся адреса датчиков и присвоенные им имена.

#### 2\. Чтение температуры

После инициализации вы можете получать актуальную температуру по имени датчика:

```python
import your_module_name

# Получение температуры
temp_outside = your_module_name.get_temp("temp_outside", temp_type=float)
print(f"Температура на улице: {temp_outside}°C")

# Получение температуры в виде строки (если нужно)
temp_inside_str = your_module_name.get_temp("temp_room", temp_type=str)
print(f"Температура в комнате: {temp_inside_str}°C")
```

-----

### 📖 API (Основные функции)

| Функция | Описание |
| :--- | :--- |
| `init_config()` | **Обязательная** функция для первого запуска. Обнаруживает новые датчики, запрашивает имена и запускает фоновое обновление температуры. |
| `get_temp(name_sensor, temp_type=float)` | Возвращает температуру для указанного **имени датчика**. `temp_type` может быть `float` (по умолчанию) или `str`. |
| `list_devices()` | Возвращает **словарь** всех подключенных 1-Wire устройств, где ключ — это **адрес** датчика, а значение — его **путь** (`pathlib.Path`). |

-----

### 📄 Формат конфигурации (`config.json`)

Конфигурационный файл содержит пути и именованные данные датчиков:

```json
{
    "path_devices": "/sys/bus/w1/devices",
    "devices": {
        "имя_датчика_1": {
            "address": "28-00000xxxxx",
            "temp_raw": "25123",
            "temp_float": 25.123,
            "temp_str": "25.123"
        },
        "имя_датчика_2": {
            "address": "10-00080xxxxx",
            "...": "..."
        }
    }
}
```
